### Backend

classDiagram
    class AdminCourseController {
        -service: CourseService
        +createCourse(data)
        +addLesson(courseId, data)
    }
    AdminCourseController --|> Controller

        +createCourse(data)
        +addLesson(courseId, data)
    }

        +saveCourse(course)

## Diagramma di Attività
```mermaid
flowchart TD
    Start([Inizio]) --> AdminLogin[Login Admin]
    AdminLogin --> Manage[Gestione Corsi]
    Manage --> Choice{Azione}
    Choice -- CreaCorso --> FormCourse[Inserisci Dati Corso]
    Choice -- AddLezione --> SelectCourse[Seleziona Corso]
    SelectCourse --> FormLesson[Inserisci Dati Lezione]
    
    FormCourse --> Save[Salva]
    FormLesson --> Save
    Save --> Validate{Valido?}
    Validate -- No --> Error[Errore]
    Error --> Manage
    Validate -- Si --> Commit[Commit DB]
    Commit --> Update[Aggiorna Vista]
    Update --> Manage
```
