# UC11 - Gestione Campi Sportivi (Admin)

## Diagramma delle Classi

Vedi [Architettura Base](Architettura_Base.md) per le classi comuni.

### Backend

```mermaid
classDiagram
    class AdminFacilityController {
        -service: FacilityService
        +resolveAction(action: string)
        -createFacility()
        -updateFacility()
        -deleteFacility()
    }
    AdminFacilityController --|> Controller

    class FacilityService {
        <<interface>>
        +create(facility: Facility) boolean
        +update(facility: Facility) boolean
        +delete(id: int) boolean
    }
    FacilityService --|> Service

    class DefaultFacilityService {
        -repository: FacilityRepository
        +create(facility: Facility) boolean
        +update(facility: Facility) boolean
        +delete(id: int) boolean
    }
    DefaultFacilityService --|> FacilityService

    class FacilityRepository {
        <<interface>>
        +save(facility: Facility) boolean
        +delete(id: int) boolean
        +findById(id: int) Facility
    }
    FacilityRepository --|> Repository
    
    DefaultFacilityService --> FacilityRepository
    AdminFacilityController --> FacilityService
```

## Diagramma di Attività

```mermaid
flowchart TD
    Start([Inizio]) --> AdminLogin[Admin Autenticato]
    AdminLogin --> MenuFacility[Gestione Campi]
    MenuFacility --> ViewList[Lista Campi]
    ViewList --> Action{Azione?}
    Action -- Crea --> ShowForm[Modulo Creazione]
    ShowForm --> SubmitCreate[Invia]
    SubmitCreate --> SaveDB[Salva]
    SaveDB --> ViewList
    Action -- Modifica --> EditForm[Modulo Modifica]
    EditForm --> SubmitEdit[Invia]
    SubmitEdit --> SaveEdit[Aggiorna]
    SaveEdit --> ViewList
    Action -- Elimina --> ConfirmDelete[Conferma]
    ConfirmDelete --> CheckDeps{Prenotazioni Attive?}
    CheckDeps -- Si --> Error[Errore Dipendenze]
    Error --> ViewList
    CheckDeps -- No --> RealDelete[Elimina]
    RealDelete --> ViewList
    Action -- Esci --> End([Fine])
```
