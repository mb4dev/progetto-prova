# UC03 - Visualizzazione Disponibilità Campi

## Diagramma delle Classi

Vedi [Architettura Base](Architettura_Base.md) per le classi comuni.

### Backend

```mermaid
classDiagram
    class AvailabilityController {
        -service: AvailabilityService
        +resolveAction(action: string)
        -getSlots()
    }
    AvailabilityController --|> Controller

    class AvailabilityService {
        <<interface>>
        +getAvailableSlots(date: Date, sport: string) Slot[]
    }
    AvailabilityService --|> Service

    class DefaultAvailabilityService {
        -repository: BookingRepository
        +getAvailableSlots(date: Date, sport: string) Slot[]
    }
    DefaultAvailabilityService --|> AvailabilityService

    class BookingRepository {
        <<interface>>
        +findBookingsByDate(date: Date) Booking[]
    }
    BookingRepository --|> Repository
    
    DefaultAvailabilityService --> BookingRepository
    AvailabilityController --> AvailabilityService
```

    actor User
