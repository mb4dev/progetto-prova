# UC12 - Gestione Corsi e Lezioni (Admin)

## Diagramma delle Classi

Vedi [Architettura Base](Architettura_Base.md) per le classi comuni.

### Backend

```mermaid
classDiagram
    class AdminCourseController {
        -service: CourseService
        +resolveAction(action: string)
        -createCourse()
        -addLesson()
    }
    AdminCourseController --|> Controller

    class CourseService {
        <<interface>>
        +createCourse(course: Course) boolean
        +addLesson(lesson: Lesson) boolean
    }
    CourseService --|> Service

    class DefaultCourseService {
        -repository: CourseRepository
        +createCourse(course: Course) boolean
        +addLesson(lesson: Lesson) boolean
    }
    DefaultCourseService --|> CourseService

    class CourseRepository {
        <<interface>>
        +saveCourse(course: Course) boolean
        +saveLesson(lesson: Lesson) boolean
    }
    CourseRepository --|> Repository
    
    DefaultCourseService --> CourseRepository
    AdminCourseController --> CourseService
```

## Diagramma di Attività

```mermaid
flowchart TD
    Start([Inizio]) --> AdminLogin[Admin Autenticato]
    AdminLogin --> MenuCourses[Gestione Corsi]
    MenuCourses --> ViewList[Lista Corsi]
    ViewList --> Action{Azione?}
    Action -- Crea Corso --> FormCourse[Modulo Corso]
    FormCourse --> SaveCourse[Salva Corso]
    SaveCourse --> ViewList
    Action -- Aggiungi Lezione --> SelectCourse[Seleziona Corso]
    SelectCourse --> FormLesson[Modulo Lezione]
    FormLesson --> SaveLesson[Salva Lezione]
    SaveLesson --> ViewList
    Action -- Esci --> End([Fine])
```
