# UC05 - Visualizzazione Corsi

## Diagramma delle Classi

Vedi [Architettura Base](Architettura_Base.md) per le classi comuni.

### Backend

```mermaid
classDiagram
    class CourseController {
        -service: CourseService
        +resolveAction(action: string)
        -getCourses()
    }
    CourseController --|> Controller

    class CourseService {
        <<interface>>
        +getAllCourses() Course[]
    }
    CourseService --|> Service

    class DefaultCourseService {
        -repository: CourseRepository
        +getAllCourses() Course[]
    }
    DefaultCourseService --|> CourseService

    class CourseRepository {
        <<interface>>
        +findAll() Course[]
    }
    CourseRepository --|> Repository
    
    DefaultCourseService --> CourseRepository
    CourseController --> CourseService
```

## Diagramma di Sequenza

### Frontend

```mermaid
sequenceDiagram
    autonumber
    actor User
    participant View as CourseListView
    participant Presenter as CoursePresenter
    participant API as APIService
    participant Backend

    User->>View: Accede a Corsi
    View->>Presenter: init()
    Presenter->>API: getCourses()
    API->>Backend: GET /courses
    Backend-->>API: {courses: [...]}
    API-->>Presenter: courses data
    Presenter->>View: displayCourses(courses)
```

### Backend (Get Courses)

```mermaid
sequenceDiagram
    autonumber
    participant Router
    participant Controller as CourseController
    participant Service as CourseService
    participant Repo as CourseRepository
    participant DB as Database

    Router->>Controller: resolve("list")
    Controller->>Service: getAllCourses()
    Service->>Repo: findAll()
    Repo->>DB: SELECT * FROM courses
    DB-->>Repo: courses list
    Repo-->>Service: courses
    Service-->>Controller: courses
    Controller-->>Router: Response 200
```
