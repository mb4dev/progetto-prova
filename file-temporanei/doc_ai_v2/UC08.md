# UC08 - Effettuare Pagamento Singolo

## Diagramma delle Classi

Vedi [Architettura Base](Architettura_Base.md) per le classi comuni.

### Backend

```mermaid
classDiagram
    class PaymentController {
        -service: PaymentService
        +resolveAction(action: string)
        -processPayment()
    }
    PaymentController --|> Controller

    class PaymentService {
        <<interface>>
        +processPayment(user: User, amount: float, method: string) boolean
    }
    PaymentService --|> Service

    class DefaultPaymentService {
        -gateway: PaymentGateway
        -repository: PaymentRepository
        +processPayment(user: User, amount: float, method: string) boolean
    }
    DefaultPaymentService --|> PaymentService

    class PaymentRepository {
        <<interface>>
        +saveTransaction(tx: Transaction) boolean
    }
    PaymentRepository --|> Repository
    
    DefaultPaymentService --> PaymentRepository
    PaymentController --> PaymentService
```

## Diagramma di Attività

```mermaid
flowchart TD
    Start([Inizio]) --> InitPayment[Inizio Processo Pagamento]
    InitPayment --> ShowAmount[Mostra Importo]
    ShowAmount --> SelectMethod[Seleziona Metodo]
    SelectMethod --> InputData[Inserisci Dati]
    InputData --> Submit[Invia Pagamento]
    Submit --> Process{Esito?}
    Process -- KO --> Error[Mostra Errore]
    Error --> Retry{Riprovare?}
    Retry -- Si --> InputData
    Retry -- No --> Cancel([Annulla])
    Process -- OK --> Success[Conferma Pagamento]
    Success --> End([Fine - Ritorna a Contesto])
```

## Diagramma di Sequenza

### Frontend

```mermaid
sequenceDiagram
    autonumber
    actor User
    participant View as PaymentView
    participant Presenter as PaymentPresenter
    participant API as APIService
    participant Backend

    User->>View: Inserisce dati (Carta/PayPal)
    View->>Presenter: processPayment(paymentData)
    Presenter->>API: pay(paymentData)
    API->>Backend: POST /payment/process
    Backend-->>API: {success: true}
    API-->>Presenter: success
    Presenter->>View: showSuccess()
    View-->>User: Chiudi modale / Avanza
```

### Backend (Payment Processing)

```mermaid
sequenceDiagram
    autonumber
    participant Router
    participant Controller as PaymentController
    participant Service as PaymentService
    participant Gateway as PaymentGateway
    participant Repo as PaymentRepository
    participant DB as Database

    Router->>Controller: resolve("process")
    Controller->>Service: processPayment(user, amount, data)
    Service->>Gateway: authorize(data)
    Gateway-->>Service: authorized
    Service->>Repo: saveTransaction(tx)
    Repo->>DB: INSERT INTO payments ...
    DB-->>Repo: success
    Repo-->>Service: true
    Service-->>Controller: success
    Controller-->>Router: Response 200
```
