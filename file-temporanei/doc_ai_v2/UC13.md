# UC13 - Gestione Tariffe e Abbonamenti (Admin)

## Diagramma delle Classi

Vedi [Architettura Base](Architettura_Base.md) per le classi comuni.

### Backend

```mermaid
classDiagram
    class AdminTariffController {
        -service: TariffService
        +resolveAction(action: string)
        -updateTariff()
    }
    AdminTariffController --|> Controller

    class TariffService {
        <<interface>>
        +updateTariff(id: int, price: float) boolean
    }
    TariffService --|> Service

    class DefaultTariffService {
        -repository: TariffRepository
        +updateTariff(id: int, price: float) boolean
    }
    DefaultTariffService --|> TariffService

    class TariffRepository {
        <<interface>>
        +updatePrice(id: int, price: float) boolean
    }
    TariffRepository --|> Repository
    
    DefaultTariffService --> TariffRepository
    AdminTariffController --> TariffService
```
