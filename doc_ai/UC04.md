## Diagramma di Sequenza

### Booking Process
```mermaid
sequenceDiagram
    autonumber
    actor User
    participant View as BookingView
    participant Presenter as BookingPresenter
    participant API as APIService
    participant Controller as BookingController
    participant Service as BookingService
    participant Pay as PaymentService
    participant Repo as BookingRepository

    User->>View: Clicca su "Prenota" (Slot X)
    View->>Presenter: onBook(slot)
    Presenter->>API: createBooking(slot)
    API->>Controller: POST /booking
    
    Controller->>Service: isSlotFree(slot)
    alt Slot Occupato
        Service-->>Controller: false
        Controller-->>API: Error 409
        API-->>Presenter: Error
        Presenter->>View: ShowError("Occupato")
    else Slot Libero
        Controller->>Pay: processPayment()
        alt Pagamento Fallito
           Pay-->>Controller: false
           Controller-->>API: Error Payment
        else Pagamento OK
           Pay-->>Controller: true
           Controller->>Service: createBooking(user, slot)
           Service->>Repo: save(booking)
           Repo-->>Service: ok
           Service-->>Controller: bookingId
           Controller-->>API: Success {id}
           API-->>Presenter: Success
           Presenter->>View: ShowConfirm()
        end
    end
```
