## Diagramma di Attività
```mermaid
flowchart TD
    Start([Inizio]) --> Access[Accedi a Storico]
    Access --> Fetch[Recupera Dati]

    Order --> Display[Mostra Lista]
    Display --> Select{Visualizza Dettaglio?}
```

## Diagramma di Sequenza
```mermaid
sequenceDiagram
    autonumber
    actor User
    participant View as HistoryView
    participant Presenter as HistoryPresenter
    participant API as APIService
    participant Controller as HistoryController
    participant Service as HistoryService
    participant Repo as HistoryRepository

    User->>View: Accede allo storico
    View->>Presenter: init()
    Presenter->>API: getHistory()
    API->>Controller: GET /history
    Controller->>Service: getHistory(userId)
    Service->>Repo: findBookingsByUser(userId)
    Service->>Repo: findSubscriptionsByUser(userId)
    Repo-->>Service: Lists
    Service->>Service: mergeAndSort()
    Service-->>Controller: List<Item>
    Controller-->>API: JSON
    API-->>Presenter: List
    Presenter->>View: renderList(list)
```
