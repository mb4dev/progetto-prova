## Diagramma delle Classi

Vedi [Architettura Base](Architettura_Base.md).

```mermaid
classDiagram
    class BookingController {
        -service: BookingService
        +cancelBooking(bookingId)
    }
    BookingController --|> Controller

    class BookingService {
        +cancel(bookingId, user)
        -checkCancellationRules(booking) bool
    }
    BookingService --|> Service

    class BookingRepository {
        +findById(id)
        +updateStatus(id, status)
    }
    BookingRepository --|> Repository

    BookingController --> BookingService
    BookingService --> BookingRepository
```

## Diagramma di Attività
```mermaid
flowchart TD
    Start([Inizio]) --> ViewHistory[Visualizza Storico (UC10)]
    ViewHistory --> SelectItem[Seleziona Prenotazione]
    SelectItem --> RequestCancel[Richiedi Cancellazione]
    RequestCancel --> CheckTime{> 24h prima?}
    CheckTime -- No --> ShowError[Errore: Troppo Tardi]
    ShowError --> End([Fine])
    CheckTime -- Si --> ProcessCancel[Processa Cancellazione]
    ProcessCancel --> UpdateDB[Aggiorna DB]
    UpdateDB --> Refund[Eventuale Rimborso]
    Refund --> Confirm[Mostra Conferma]
    Confirm --> End
```

## Diagramma di Sequenza
```mermaid
sequenceDiagram
    autonumber
    actor User
    participant View as HistoryView
    participant Presenter as HistoryPresenter
    participant API as APIService
    participant Controller as BookingController
    participant Service as BookingService
    participant Repo as BookingRepository
    
    User->>View: Clicca "Cancella"
    View->>Presenter: cancel(id)
    Presenter->>API: cancelBooking(id)
    API->>Controller: POST /booking/cancel
    Controller->>Service: cancel(id, user)
    Service->>Repo: findById(id)
    Repo-->>Service: booking
    Service->>Service: checkCancellationRules()
    alt Violazione Regole (<24h)
        Service-->>Controller: Error Rules
        Controller-->>API: 400 Bad Request
        API-->>Presenter: Error
        Presenter->>View: ShowError("Non cancellabile")
    else OK
        Service->>Repo: updateStatus(id, "CANCELLED")
        Repo-->>Service: ok
        Service-->>Controller: Success
        Controller-->>API: 200 OK
        API-->>Presenter: Success
        Presenter->>View: refreshHistory()
    end
```
