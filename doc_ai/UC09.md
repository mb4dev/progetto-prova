## Diagramma di Attività
```mermaid
flowchart TD
    Start([Inizio]) --> ListPlans[Lista Abbonamenti]
    ListPlans --> Select[Seleziona Piano]
    Select --> CheckActive{Ha già abbonamento?}
    CheckActive -- Si --> ShowInfo[Avviso Già Attivo]
    ShowInfo --> End([Fine])
    CheckActive -- No --> Pay[Pagamento (UC08)]
    Pay --> Result{Esito?}
    Result -- No --> ShowError
    Result -- Si --> Activate[Attiva Abbonamento]
    Activate --> SetDates[Imposta Scadenza]
    SetDates --> Save[Salva DB]
    Save --> Confirm[Conferma]
    Confirm --> End
```

## Diagramma di Sequenza
```mermaid
sequenceDiagram
    autonumber
    actor User
    participant View as SubscriptionView
    participant Presenter as SubscriptionPresenter
    participant API as APIService
    participant Controller as SubscriptionController
    participant Service as SubscriptionService
    participant Repo as SubscriptionRepository

    User->>View: Seleziona Abbonamento
    View->>Presenter: purchase(planId)
    Presenter->>API: purchaseSubscription(planId)
    API->>Controller: POST /subscriptions/buy
    Controller->>Service: checkActive(user)
    alt Already Active
        Service-->>Controller: Error Exists
        Controller-->>API: 409 Conflict
        API-->>Presenter: Error
        Presenter->>View: ShowAlert("Hai già un abbonamento")
    else None Active
        Controller->>Service: Payment flow...
        Service-->>Controller: Payment OK
        Controller->>Service: createSubscription(user, plan)
        Service->>Repo: save()
        Repo-->>Service: OK
        Service-->>Controller: OK
        Controller-->>API: 200 OK
        API-->>Presenter: Success
        Presenter->>View: ShowSuccess()
    end
```
