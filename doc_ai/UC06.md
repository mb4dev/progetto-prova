# UC06 - Iscrizione a una lezione di un corso

## Diagramma delle Classi

Vedi [Architettura Base](Architettura_Base.md).

### Backend
```mermaid
classDiagram
    class CourseController {
        -service: CourseService
        -payService: PaymentService
        +subscribeToLesson(user, lessonId)
    }
    CourseController --|> Controller

    class CourseService {
        +subscribe(user, lesson) Subscription
    }
    CourseService --|> Service
    
    class Lesson {
        +id: int
        +maxSpots: int
        +occupiedSpots: int
    }

    class CourseRepository {
        +findLesson(id)
        +saveSubscription(sub)
        +incrementOccupied(lessonId)
    }
    CourseRepository --|> Repository

    CourseController --> CourseService
    CourseService --> CourseRepository
    CourseRepository --> Lesson
```

## Diagramma di Attività
```mermaid
flowchart TD
    Start([Inizio]) --> ViewList[Visualizza Corsi (UC05)]
    ViewList --> SelectCourse[Seleziona Corso]
    SelectCourse --> ViewLessons[Visualizza Lezioni]
    ViewLessons --> SelectLesson[Seleziona Lezione]
    SelectLesson --> CheckSpots{Posti Disponibili?}
    CheckSpots -- No --> ShowError[Avviso Posti Esauriti]
    ShowError --> End([Fine])
    CheckSpots -- Si --> Pay[Pagamento (UC08)]
    Pay --> PayResult{Esito OK?}
    PayResult -- No --> ShowPayError[Errore Pagamento]
    ShowPayError --> End
    PayResult -- Si --> Register[Registra Iscrizione]
    Register --> UpdateSpots[Aggiorna Posti]
    UpdateSpots --> Confirm[Mostra Conferma]
    Confirm --> End
```

## Diagramma di Sequenza
```mermaid
sequenceDiagram
    autonumber
    actor User
    participant View as LessonDetailView
    participant Presenter as LessonPresenter
    participant API as APIService
    participant Controller as CourseController
    participant Service as CourseService
    participant Pay as PaymentService
    participant Repo as CourseRepository

    User->>View: Clicca "Iscriviti"
    View->>Presenter: onSubscribe(lessonId)
    Presenter->>API: subscribe(lessonId)
    API->>Controller: POST /courses/subscribe
    
    Controller->>Service: checkAvailability(lessonId)
    Service-->>Controller: true/false
    alt No Posti
        Controller-->>API: Error 409
        API-->>Presenter: Error "Full"
        Presenter->>View: showError("Posti esauriti")
    else Posti OK
        Controller->>Pay: processPayment()
        alt Pay Error
            Pay-->>Controller: false
            Controller-->>API: Error Pay
        else Pay OK
            Pay-->>Controller: true
            Controller->>Service: subscribe(user, lessonId)
            Service->>Repo: saveSubscription()
            Service->>Repo: incrementOccupied(lessonId)
            Service-->>Controller: success
            Controller-->>API: 200 OK
            API-->>Presenter: success
            Presenter->>View: showSuccess()
        end
    end
```
