#### Diagramma delle classi 

#### Backend

- **DIAGRAMMI CLASSI REPOSITORY**
``` mermaid 
classDiagram
class Repository {
    <<abstract>>
    #connection: PDO
}

class UserRepository {
    <<abstract>>
    getById(id) User
    update(user) bool
}

class DefaultUserRepository {
    getById(id) User
    update(user) bool
}

UserRepository --|> Repository        
DefaultUserRepository --|> UserRepository  
Repository --> PDO : usa
```

- **DIAGRAMMI CLASSI SERVICE**

``` mermaid 
classDiagram
class UserService{
    <<interface>>
    getProfile(id) Response
    updateProfile(id, data) Response
}

class DefaultUserService {
    - userRepository : UserRepository
    getProfile(id) Response
    updateProfile(id, data) Response
}

DefaultUserService ..|> UserService
DefaultUserService --> UserRepository
UserService --> Response
```

- **Diagramma FRONTEND**
``` mermaid 
classDiagram
    class View {

    }

    ProfileView --|> View
```

#### Diagramma attività
``` mermaid 
flowchart TD

Start([Inizio]) --> AuthCheck{Autenticato?}
AuthCheck -->|No| Login[Redirect a Login]
AuthCheck -->|Sì| LoadProfile[Caricamento dati profilo]

LoadProfile --> Display[Mostra profilo]
Display --> Choice{Cosa fare?}

Choice -->|Modifica| EditInput[Inserisce nuovi dati]
Choice -->|Esci| End([Fine])

EditInput --> Validate{Dati validi?}
Validate -->|No| ShowError[Mostra errore validazione]
ShowError --> EditInput

Validate -->|Sì| SaveData[Salva modifiche nel DB]
SaveData --> DBCheck{Salvataggio OK?}
DBCheck -->|No| DBError[Mostra errore sistema]
DBCheck -->|Sì| Success[Mostra conferma e aggiorna vista]
Success --> Display
```

#### Diagramma di sequenza
##### Frontend 

``` mermaid
sequenceDiagram
    autonumber
    actor user as Utente
    participant nav as App   
    participant view as ProfileView
    participant presenter as ProfilePresenter
    participant api as APIService
    participant backend as Backend

    nav ->>+ presenter: init()
    presenter ->>+ api: getProfile(userId)
    api ->>+ backend: GET /user/profile
    backend -->>- api: {success: true, data}
    api -->>- presenter: {success: true, data}
    presenter ->>+ view: display(data)
    view -->> user: mostra dati profilo
    
    user ->> view: modifica dati e clicca "Salva"
    view ->> presenter: notify(updateProfile)
    presenter ->> api: updateProfile(userId, data)
    api ->> backend: POST /user/update
    backend -->> api: {success: true, message}
    api -->> presenter: {success: true, message}
    presenter ->> view: display(success)
```

##### Backend
``` mermaid
sequenceDiagram

autonumber

participant frontend as Frontend
participant router as :Router
participant controller as :UserController
participant service as :UserService
participant repository as :UserRepository
participant db as Database

frontend ->>+ router: HTTP GET /user/profile
router ->>+ controller: resolveAction("getProfile")
controller ->>+ service: getProfile(userId)
service ->>+ repository: getById(userId)
repository ->>+ db: SELECT * FROM users
db -->>- repository: user data
repository -->>- service: User
service -->>- controller: Response(200, success, data)
controller -->>- router: Response
router -->>- frontend: HTTP Response
```
