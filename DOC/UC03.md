### Diagrammi caso d'uso UC03 - Visualizzazione disponibilità campi

#### Diagramma delle classi

##### Backend
```mermaid
classDiagram
    class FieldRepository {
        <<abstract>>
        +getAvailability(fieldId, date) list
    }
    class DefaultFieldRepository {
        +getAvailability(fieldId, date) list
    }
    class BookingService {
        <<interface>>
        +getFieldAvailability(fieldId, date) Response
    }
    class DefaultBookingService {
        -fieldRepository: FieldRepository
        +getFieldAvailability(fieldId, date) Response
    }
    class BookingController {
        -bookingService: BookingService
        +resolve(action) Response
    }

    DefaultFieldRepository --|> FieldRepository
    DefaultBookingService ..|> BookingService
    DefaultBookingService --> FieldRepository
    BookingController --> BookingService
```

##### Frontend
```mermaid
classDiagram
    class AvailabilityView {
        +display(slots)
        +template()
    }
    class AvailabilityPresenter {
        -view: AvailabilityView
        -service: APIService
        +init()
        -fetchAvailability(date)
    }
    AvailabilityView --|> View
    AvailabilityPresenter --|> Presenter
    AvailabilityPresenter --> AvailabilityView
    AvailabilityPresenter --> APIService
```

#### Diagramma attività
```mermaid
flowchart TD
    Start([Inizio]) --> SelectSport[Seleziona sport/campo]
    SelectSport --> FetchData[Sistema interroga DB per slot occupati]
    FetchData --> ShowCalendar[Mostra calendario con slot disponibili]
    ShowCalendar --> Choice{Navigare?}
    Choice -->|Sì| UpdateDate[Cambia data/settimana]
    UpdateDate --> FetchData
    Choice -->|No| End([Fine])
```

#### Diagramma di sequenza
##### Frontend
```mermaid
sequenceDiagram
    autonumber
    actor user as Utente
    participant view as AvailabilityView
    participant presenter as AvailabilityPresenter
    participant api as APIService
    participant backend as Backend

    user ->> view: Seleziona campo e data
    view ->> presenter: notify(changeDate)
    presenter ->> api: getAvailability(fieldId, date)
    api ->> backend: GET /fields/availability
    backend -->> api: list of slots
    api -->> presenter: list of slots
    presenter ->> view: display(list of slots)
```
