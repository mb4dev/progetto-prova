### Diagrammi caso d'uso UC02 - Gestione profilo utente

#### Diagramma delle classi

##### Backend
```mermaid
classDiagram
    class UserRepository {
        <<abstract>>
        +getUser(id) User
        +updateUser(user) bool
    }
    class DefaultUserRepository {
        +getUser(id) User
        +updateUser(user) bool
    }
    class UserService {
        <<interface>>
        +getProfile(userId) Response
        +updateProfile(userId, data) Response
    }
    class DefaultUserService {
        -userRepository: UserRepository
        +getProfile(userId) Response
        +updateProfile(userId, data) Response
    }
    class UserController {
        -userService: UserService
        +resolve(action) Response
    }

    DefaultUserRepository --|> UserRepository
    DefaultUserService ..|> UserService
    DefaultUserService --> UserRepository
    UserController --> UserService
```

##### Frontend
```mermaid
classDiagram
    class ProfileView {
        +display(userData)
        +template()
    }
    class ProfilePresenter {
        -view: ProfileView
        -service: APIService
        +init()
        -handleUpdate(data)
    }
    ProfileView --|> View
    ProfilePresenter --|> Presenter
    ProfilePresenter --> ProfileView
    ProfilePresenter --> APIService
```

#### Diagramma attività
```mermaid
flowchart TD
    Start([Inizio]) --> GetProfile[Richiede dati profilo]
    GetProfile --> ShowData[Mostra dati attuali]
    ShowData --> Choice{Modificare?}
    Choice -->|No| End([Fine])
    Choice -->|Sì| Edit[Modifica campi]
    Edit --> Submit[Invia modifiche]
    Submit --> Validate{Dati validi?}
    Validate -->|No| Error[Mostra errore]
    Error --> Edit
    Validate -->|Sì| Save[Salva nel DB]
    Save --> Success[Conferma successo]
    Success --> End
```

#### Diagramma di sequenza
##### Frontend
```mermaid
sequenceDiagram
    autonumber
    actor user as Utente
    participant view as ProfileView
    participant presenter as ProfilePresenter
    participant api as APIService
    participant backend as Backend

    user ->> view: Click su "Profilo"
    view ->> presenter: notify(load)
    presenter ->> api: getProfile()
    api ->> backend: GET /user/profile
    backend -->> api: UserData
    api -->> presenter: UserData
    presenter ->> view: display(UserData)
    user ->> view: Modifica dati e clicca "Salva"
    view ->> presenter: notify(update, data)
    presenter ->> api: updateProfile(data)
    api ->> backend: POST /user/update
    backend -->> api: success
    api -->> presenter: success
    presenter ->> view: display(success)
```
