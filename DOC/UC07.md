### Diagrammi caso d'uso UC07 - Cancellare prenotazione

#### Diagramma delle classi

##### Backend
```mermaid
classDiagram
    class BookingRepository {
        <<abstract>>
        +getBooking(id) Booking
        +updateStatus(id, status) bool
    }
    class DefaultBookingRepository {
        +getBooking(id) Booking
        +updateStatus(id, status) bool
    }
    class BookingService {
        <<interface>>
        +cancelBooking(userId, bookingId) Response
    }
    class DefaultBookingService {
        -bookingRepository: BookingRepository
        -refundService: RefundService
        +cancelBooking(userId, bookingId) Response
    }
    class BookingController {
        -bookingService: BookingService
        +resolve(action) Response
    }

    DefaultBookingRepository --|> BookingRepository
    DefaultBookingService ..|> BookingService
    DefaultBookingService --> BookingRepository
    BookingController --> BookingService
```

#### Diagramma attività
```mermaid
flowchart TD
    Start([Inizio]) --> ViewHistory[Visualizza storico UC10]
    ViewHistory --> SelectBooking[Seleziona prenotazione da cancellare]
    SelectBooking --> CheckPolicy{Mancano +24 ore?}
    CheckPolicy -->|No| Reject[Mostra errore: Tempo scaduto]
    CheckPolicy -->|Sì| UpdateDB[Imposta stato 'cancellata' e rimborsa]
    UpdateDB --> Success[Conferma cancellazione]
    Success --> End([Fine])
```

#### Diagramma di sequenza
##### Frontend
```mermaid
sequenceDiagram
    autonumber
```
