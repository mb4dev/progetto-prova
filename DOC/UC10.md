### Diagrammi caso d'uso UC10 - Visualizzare storico prenotazioni e pagamenti

#### Diagramma delle classi

##### Backend
```mermaid
classDiagram
    class HistoryRepository {
        <<abstract>>
        +getUserHistory(userId) list
    }
    class DefaultHistoryRepository {
        +getUserHistory(userId) list
    }
    class HistoryService {
        <<interface>>
        +getHistory(userId) Response
    }
    class DefaultHistoryService {
        -historyRepository: HistoryRepository
        +getHistory(userId) Response
    }
    class HistoryController {
        -historyService: HistoryService
        +resolve(action) Response
    }

    DefaultHistoryRepository --|> HistoryRepository
    DefaultHistoryService ..|> HistoryService
    DefaultHistoryService --> HistoryRepository
    HistoryController --> HistoryService
```

##### Frontend
```mermaid
classDiagram
    class HistoryView {
        +display(items)
        +template()
    }
    class HistoryPresenter {
        -view: HistoryView
        -service: APIService
        +init()
        -fetchHistory()
    }
    HistoryView --|> View
    HistoryPresenter --|> Presenter
    HistoryPresenter --> HistoryView
    HistoryPresenter --> APIService
```

#### Diagramma attività
```mermaid
flowchart TD
    Start([Inizio]) --> AccessHistory[Accede alla sezione storico]
    AccessHistory --> FetchData[Sistema recupera dati dal DB]
    FetchData --> ShowList[Mostra elenco ordinato cronologicamente]
    ShowList --> DetailChoices{Visualizzare dettaglio?}
    DetailChoices -->|Sì| ShowDetail[Mostra dettagli completi voce]
    ShowDetail --> ShowList
    DetailChoices -->|No| End([Fine])
```

#### Diagramma di sequenza
##### Frontend
```mermaid
sequenceDiagram
    autonumber
    actor user as Utente
    participant view as HistoryView
    participant presenter as HistoryPresenter
    participant api as APIService
    participant backend as Backend

    user ->> view: Click su "Storico"
    view ->> presenter: notify(load)
    presenter ->> api: getHistory()
    api ->> backend: GET /history
    backend -->> api: list of items
    api -->> presenter: list of items
    presenter ->> view: display(list of items)
```
