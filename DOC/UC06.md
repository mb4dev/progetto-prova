### Diagrammi caso d'uso UC06 - Iscriversi a una lezione di un corso

#### Diagramma delle classi

##### Backend
```mermaid
classDiagram
    class LessonRepository {
        <<abstract>>
        +getLessonsByCourse(courseId) list
        +joinLesson(userId, lessonId) bool
        +hasAvailableSlots(lessonId) bool
    }
    class DefaultLessonRepository {
        +getLessonsByCourse(courseId) list
        +joinLesson(userId, lessonId) bool
        +hasAvailableSlots(lessonId) bool
    }
    class CourseService {
        <<interface>>
        +joinLesson(userId, lessonId) Response
    }
    class DefaultCourseService {
        -lessonRepository: LessonRepository
        -paymentService: PaymentService
        +joinLesson(userId, lessonId) Response
    }
    class CourseController {
        -courseService: CourseService
        +resolve(action) Response
    }

    DefaultLessonRepository --|> LessonRepository
    DefaultCourseService ..|> CourseService
    DefaultCourseService --> LessonRepository
    CourseController --> CourseService
```

#### Diagramma attività
```mermaid
flowchart TD
    Start([Inizio]) --> ViewCourses[Visualizza corsi UC05]
    ViewCourses --> SelectCourse[Seleziona corso e visualizza lezioni]
    SelectCourse --> CheckSlots{Posti disponibili?}
    CheckSlots -->|No| ErrorSlot[Mostra errore: Posti esauriti]
    CheckSlots -->|Sì| Payment{Pagamento?}
    Payment -->|No| ErrorPay[Mostra errore pagamento]
    Payment -->|Sì| Confirm[Conferma iscrizione e aggiorna posti]
    Confirm --> Success[Messaggio successo]
    Success --> End([Fine])
```

##### Frontend

sequenceDiagram
