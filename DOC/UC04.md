### Diagrammi caso d'uso UC04 - Prenotare campo sportivo

#### Diagramma delle classi

##### Backend
```mermaid
classDiagram
    class BookingRepository {
        <<abstract>>
        +createBooking(bookingData) bool
        +isSlotAvailable(fieldId, startTime, endTime) bool
    }
    class DefaultBookingRepository {
        +createBooking(bookingData) bool
        +isSlotAvailable(fieldId, startTime, endTime) bool
    }
    class BookingService {
        <<interface>>
        +bookField(userId, bookingData) Response
    }
    class DefaultBookingService {
        -bookingRepository: BookingRepository
        -paymentService: PaymentService
        +bookField(userId, bookingData) Response
    }
    class BookingController {
        -bookingService: BookingService
        +resolve(action) Response
    }

    DefaultBookingRepository --|> BookingRepository
    DefaultBookingService ..|> BookingService
    DefaultBookingService --> BookingRepository
    BookingController --> BookingService
```

#### Diagramma attività
```mermaid
flowchart TD
    Start([Inizio]) --> ViewAvailability[Visualizza disponibilità UC03]
    ViewAvailability --> SelectSlot[Seleziona slot libero]
    SelectSlot --> LockSlot[Sistema blocca temporaneamente slot]
    LockSlot --> Payment{Pagamento?}
    Payment -->|Fallito| UnlockSlot[Rilascia slot]
    UnlockSlot --> Error[Mostra errore]
    Payment -->|Riuscito| Confirm[Registra e conferma prenotazione]
    Confirm --> Success[Messaggio successo]
    Success --> End([Fine])
```
