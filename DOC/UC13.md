### Diagrammi caso d'uso UC13 - Gestire tariffe e abbonamenti (Admin)

#### Diagramma delle classi

##### Backend
```mermaid
classDiagram
    class PricingRepository {
        <<abstract>>
        +updatePricing(type, price) bool
        +getPricing() list
        +manageSubscriptionPlans(data) bool
    }
    class DefaultPricingRepository {
        +updatePricing(type, price) bool
        +getPricing() list
        +manageSubscriptionPlans(data) bool
    }
    class AdminService {
        <<interface>>
        +managePricing(data) Response
    }
    class DefaultAdminService {
        -pricingRepository: PricingRepository
        +managePricing(data) Response
    }
    class AdminController {
        -adminService: AdminService
        +resolve(action) Response
    }

    DefaultPricingRepository --|> PricingRepository
    DefaultAdminService ..|> AdminService
    DefaultAdminService --> PricingRepository
    AdminController --> AdminService
```

##### Frontend
```mermaid
classDiagram
    class AdminPricingView {
        +display(pricing)
        +template()
    }
    class AdminPricingPresenter {
        -view: AdminPricingView
        -service: APIService
        +init()
        -handleSave(data)
    }
    AdminPricingView --|> View
    AdminPricingPresenter --|> Presenter
    AdminPricingPresenter --> AdminPricingView
    AdminPricingPresenter --> APIService
```

#### Diagramma attività
```mermaid
flowchart TD
    Start([Inizio]) --> AccessPricing[Accede alla sezione gestione tariffe]
    AccessPricing --> ShowCurrent[Mostra tariffe e abbonamenti attuali]
    ShowCurrent --> Action[Crea, modifica o disattiva tariffe]
    Action --> Validate[Sistema valida e salva modifiche]
    Validate --> Apply[Nuove tariffe applicate alle prenotazioni successive]
    Apply --> End([Fine])
```

#### Diagramma di sequenza
##### Frontend
```mermaid
sequenceDiagram
    autonumber
    actor admin as Admin
    participant view as AdminPricingView
    participant presenter as AdminPricingPresenter
    participant api as APIService
    participant backend as Backend

    admin ->> view: Modifica tariffe
    view ->> presenter: notify(update, data)
    presenter ->> api: updatePricing(data)
    api ->> backend: POST /admin/pricing/update
    backend -->> api: Result
    api -->> presenter: Result
    presenter ->> view: display(Result)
```
