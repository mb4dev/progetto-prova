# UC06 - Iscrizione a una Lezione di un Corso

## Diagramma delle Classi

Vedi [Architettura Base](Architettura_Base.md) per le classi comuni.

### Backend

```mermaid
classDiagram
    class CourseController {
        -service: CourseService
        +resolveAction(action: string)
        -subscribe()
    }
    CourseController --|> Controller

    class CourseService {
        <<interface>>
        +subscribeToLesson(user: User, lessonId: int) boolean
    }
    CourseService --|> Service

    class DefaultCourseService {
        -repository: CourseRepository
        +subscribeToLesson(user: User, lessonId: int) boolean
    }
    DefaultCourseService --|> CourseService

    class CourseRepository {
        <<interface>>
        +addSubscriber(lessonId: int, userId: int) boolean
        +hasSpace(lessonId: int) boolean
    }
    CourseRepository --|> Repository
    
    DefaultCourseService --> CourseRepository
    CourseController --> CourseService
```

## Diagramma di Attività

```mermaid
flowchart TD
    Start([Inizio]) --> ViewCourses[Visualizza Corsi (UC05)]
    ViewCourses --> SelectLesson[Seleziona Lezione]
    SelectLesson --> CheckSpace{Posti Disponibili?}
    CheckSpace -- No --> Error[Mostra Errore]
    Error --> ViewCourses
    CheckSpace -- Si --> Payment[Pagamento (UC08) o Abbonamento]
    Payment --> PayResult{Pagamento OK?}
    PayResult -- No --> Error
    PayResult -- Si --> Subscribe[Registra Iscrizione]
    Subscribe --> Confirm[Mostra Conferma]
    Confirm --> End([Fine])
```

## Diagramma di Sequenza

### Frontend

```mermaid
sequenceDiagram
    autonumber
    actor User
    participant View as CourseDetailView
    participant Presenter as CoursePresenter
    participant API as APIService
    participant Backend

    User->>View: Seleziona "Iscriviti"
    View->>Presenter: subscribeToLesson(lessonId)
    Presenter->>API: subscribe(lessonId)
    API->>Backend: POST /courses/subscribe
    Backend-->>API: {success: true}
    API-->>Presenter: success
    Presenter->>View: showSuccess()
```

### Backend (Subscribe)

```mermaid
sequenceDiagram
    autonumber
    participant Router
    participant Controller as CourseController
    participant Service as CourseService
    participant Repo as CourseRepository
    participant DB as Database

    Router->>Controller: resolve("subscribe")
    Controller->>Service: subscribeToLesson(user, lessonId)
    Service->>Repo: hasSpace(lessonId)
    Repo-->>Service: true
    Service->>Repo: addSubscriber(lessonId, userId)
    Repo->>DB: INSERT INTO lesson_subs ...
    DB-->>Repo: success
    Repo-->>Service: true
    Service-->>Controller: success
    Controller-->>Router: Response 201
```
