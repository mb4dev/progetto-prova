# UC02 - Gestione Profilo Utente

## Diagramma delle Classi

Vedi [Architettura Base](Architettura_Base.md) per le classi comuni.

### Backend

```mermaid
classDiagram
    class ProfileController {
        -service: ProfileService
        +resolveAction(action: string)
        -getProfile()
        -updateProfile()
    }
    ProfileController --|> Controller

    class ProfileService {
        <<interface>>
        +getProfile(userId: int) User
        +updateProfile(user: User) boolean
    }
    ProfileService --|> Service

    class DefaultProfileService {
        -repository: UserRepository
        +getProfile(userId: int) User
        +updateProfile(user: User) boolean
    }
    DefaultProfileService --|> ProfileService

    class UserRepository {
        <<interface>>
        +findById(id: int) User
        +update(user: User) boolean
    }
    UserRepository --|> Repository
    
    class DefaultUserRepository {
        -connection: PDOConnection
    }
    DefaultUserRepository --|> UserRepository

    ProfileController --> ProfileService
    DefaultProfileService --> UserRepository
```

## Diagramma di Attività

```mermaid
flowchart TD
    Start([Inizio]) --> Login[Utente Autenticato]
    Login --> AccessProfile[Accedi a sezione Profilo]
    AccessProfile --> ViewProfile[Visualizza Dati]
    ViewProfile --> EditChoice{Modifica?}
    EditChoice -- No --> End([Fine])
    EditChoice -- Si --> EditForm[Modifica Campi]
    EditForm --> Submit[Invia Modifiche]
    Submit --> Validate{Dati Validi?}
    Validate -- No --> ShowError[Errore Validazione]
    ShowError --> EditForm
    Validate -- Si --> SaveDB[Salva su DB]
    SaveDB --> Success{Salvataggio OK?}
    Success -- No --> ShowSysError[Errore Sistema]
    ShowSysError --> End
    Success -- Si --> UpdateView[Aggiorna Vista]
    UpdateView --> End
```

## Diagramma di Sequenza

### Frontend

```mermaid
sequenceDiagram
    autonumber
    actor User
    participant View as ProfileView
    participant Presenter as ProfilePresenter
    participant API as APIService
    participant Backend

    User->>View: Accede al profilo
    View->>Presenter: init()
    Presenter->>API: getProfile()
    API->>Backend: GET /profile
    Backend-->>API: {user: ...}
    API-->>Presenter: User Data
    Presenter->>View: display(user)
    
    User->>View: Modifica dati e conferma
    View->>Presenter: updateProfile(newData)
    Presenter->>API: updateProfile(newData)
    API->>Backend: POST /profile/update
    Backend-->>API: {success: true}
    API-->>Presenter: success
    Presenter->>View: showSuccess()
```

### Backend (Update Flow)

```mermaid
sequenceDiagram
    autonumber
    participant Router
    participant Controller as ProfileController
    participant Service as ProfileService
    participant Repo as UserRepository
    participant DB as Database

    Router->>Controller: resolve("update")
    Controller->>Service: updateProfile(user)
    Service->>Repo: update(user)
    Repo->>DB: UPDATE users SET ...
    DB-->>Repo: affected rows
    Repo-->>Service: true
    Service-->>Controller: success
    Controller-->>Router: Response 200
```
