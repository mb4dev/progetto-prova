# UC07 - Cancellazione Prenotazione

## Diagramma delle Classi

Vedi [Architettura Base](Architettura_Base.md) per le classi comuni.

### Backend

```mermaid
classDiagram
    class BookingController {
        -service: BookingService
        +resolveAction(action: string)
        -cancelBooking()
    }
    BookingController --|> Controller

    class BookingService {
        <<interface>>
        +cancelBooking(user: User, bookingId: int) boolean
    }
    BookingService --|> Service

    class DefaultBookingService {
        -repository: BookingRepository
        +cancelBooking(user: User, bookingId: int) boolean
    }
    DefaultBookingService --|> BookingService

    class BookingRepository {
        <<interface>>
        +updateStatus(bookingId: int, status: string) boolean
        +getBooking(bookingId: int) Booking
    }
    BookingRepository --|> Repository
    
    DefaultBookingService --> BookingRepository
    BookingController --> BookingService
```

## Diagramma di Attività

```mermaid
flowchart TD
    Start([Inizio]) --> ViewHistory[Visualizza Storico (UC10)]
    ViewHistory --> SelectItem[Seleziona Prenotazione]
    SelectItem --> CheckTime{> 24h Prima?}
    CheckTime -- No --> Error[Mostra Errore: Troppo Tardi]
    Error --> ViewHistory
    CheckTime -- Si --> Confirm{Conferma?}
    Confirm -- No --> ViewHistory
    Confirm -- Si --> CancelReq[Richiedi Cancellazione]
    CancelReq --> Success{Cancellazione OK?}
    Success -- No --> SysError[Errore Sistema]
    Success -- Si --> Refund[Eventuale Rimborso]
    Refund --> UpdateView[Aggiorna Lista]
    UpdateView --> End([Fine])
```

## Diagramma di Sequenza

### Frontend

```mermaid
sequenceDiagram
    autonumber
    actor User
    participant View as HistoryView
    participant Presenter as HistoryPresenter
    participant API as APIService
    participant Backend

    User->>View: Clicca "Cancella"
    View->>Presenter: cancelBooking(bookingId)
    Presenter->>API: cancelBooking(bookingId)
    API->>Backend: POST /booking/cancel
    Backend-->>API: {success: true}
    API-->>Presenter: success
    Presenter->>View: removeEntry(bookingId)
    View-->>User: Feedback visivo
```

### Backend (Cancel)

```mermaid
sequenceDiagram
    autonumber
    participant Router
    participant Controller as BookingController
    participant Service as BookingService
    participant Repo as BookingRepository
    participant DB as Database

    Router->>Controller: resolve("cancel")
    Controller->>Service: cancelBooking(user, bookingId)
    Service->>Repo: getBooking(bookingId)
    Repo-->>Service: booking
    Service->>Service: checkTimeConstraint(booking)
    Service->>Repo: updateStatus(bookingId, "CANCELLED")
    Repo->>DB: UPDATE bookings ...
    DB-->>Repo: success
    Repo-->>Service: true
    Service-->>Controller: success
    Controller-->>Router: Response 200
```
