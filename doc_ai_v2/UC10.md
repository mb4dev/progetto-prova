# UC10 - Visualizzazione Storico Prenotazioni e Pagamenti

## Diagramma delle Classi

Vedi [Architettura Base](Architettura_Base.md) per le classi comuni.

### Backend

```mermaid
classDiagram
    class HistoryController {
        -service: HistoryService
        +resolveAction(action: string)
        -getHistory()
    }
    HistoryController --|> Controller

    class HistoryService {
        <<interface>>
        +getUserHistory(user: User) HistoryItem[]
    }
    HistoryService --|> Service

    class DefaultHistoryService {
        -bookingRepo: BookingRepository
        -paymentRepo: PaymentRepository
        -subRepo: SubscriptionRepository
        +getUserHistory(user: User) HistoryItem[]
    }
    DefaultHistoryService --|> HistoryService

    DefaultHistoryService --> BookingRepository
    DefaultHistoryService --> PaymentRepository
    DefaultHistoryService --> SubscriptionRepository
    HistoryController --> HistoryService
```

## Diagramma di Attività

```mermaid
flowchart TD
    Start([Inizio]) --> Login[Utente Autenticato]

    SelectHistory --> FetchData[Richiedi Dati]

    RenderList --> Filter{Filtra/Dettaglio?}

```

## Diagramma di Sequenza

### Frontend

```mermaid
sequenceDiagram
    autonumber
    actor User
    participant View as HistoryView
    participant Presenter as HistoryPresenter
    participant API as APIService
    participant Backend

    User->>View: Accede allo Storico
    View->>Presenter: init()
    Presenter->>API: getHistory()
    API->>Backend: GET /history
    Backend-->>API: {items: [...]}
    API-->>Presenter: history data
    Presenter->>View: displayHistory(items)
```

### Backend (Get History)

```mermaid
sequenceDiagram
    autonumber
    participant Router
    participant Controller as HistoryController
    participant Service as HistoryService
    participant RepoB as BookingRepository
    participant RepoP as PaymentRepository
    participant DB as Database

    Router->>Controller: resolve("get")
    Controller->>Service: getUserHistory(user)
    Service->>RepoB: findByUser(user)
    RepoB->>DB: SELECT bookings...
    DB-->>RepoB: bookings
    Service->>RepoP: findByUser(user)
    RepoP->>DB: SELECT payments...
    DB-->>RepoP: payments
    Service->>Service: mergeAndSort(bookings, payments)
    Service-->>Controller: historyItems
    Controller-->>Router: Response 200
```
