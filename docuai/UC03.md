# UC03 - Visualizzazione Disponibilità Campi

Per inizializzazione dei componenti o componenti comuni a tutto il software vedere [Architettura base](./Architettura%20base.md)

---

## Specifica Funzionale

| **Caso d'uso**        | Visualizzazione disponibilità |
| --------------------- | ------------------------------ |
| **ID**                | UC03 |
| **Descrizione**       | L'utente visualizza gli slot temporali liberi per i campi sportivi |
| **Attore principale** | Utente |
| **Attore secondario** | Sistema |
| **Precondizioni**     | 1. L'utente è autenticato. |
| **Postcondizioni**    | 1. Viene mostra un calendario con gli slot temporali disponibili. |
| **Flusso principale** | 1. L'utente seleziona lo sport.<br>2. Il sistema mostra il calendario per lo sport selezionato.<br>3. Il sistema evidenzia gli slot occupati.<br>4. L'utente può navigare tra le settimane. |

---

## Diagramma di Attività

```mermaid 
flowchart TD
    Start([Inizio]) --> LoadSports[CampiPresenter carica lista sport]
    LoadSports --> ShowSports[CampiView mostra griglia sport]

    ShowSports --> SelectSport[Utente seleziona uno sport]
    SelectSport --> Navigate[EventBus notifica navigazione]
    Navigate --> InitCalendar[Inizializzazione CalendarView e CalendarPresenter]
    
    InitCalendar --> InitComponents[Inizializzazione DatePicker e SlotPicker]
    InitComponents --> DefaultDate[DatePicker imposta data default]
    DefaultDate --> FetchSlots[SlotPickerPresenter richiede slot occupati]
    
    FetchSlots --> ShowSlots[SlotPicker mostra griglia orari]
    ShowSlots --> End([Fine UC03])
```

### Backend

#### Caso GET /fields/
```mermaid
sequenceDiagram
    autonumber

    participant frontend as Frontend
    participant router as Router
    participant controller as :FieldController
    participant service as :FieldService
    participant fieldRepo as :FieldRepository
    participant bookingRepo as :BookingRepository
    participant db as Database

    frontend ->>+ router: GET /fields/
    router ->>+ controller: resolveAction()
    controller ->>+ service: getFields()
    
    service ->>+ fieldRepo: getFields()
    fieldRepo ->>+ db: query
    db -->>- fieldRepo: field data
    fieldRepo -->>- service: Field[]
    alt success
        service -->>- controller: Response(200, success, fields)
        controller -->> router: Response(200, success, fields)
    else db error
        fieldRepo -->> service: throw Exception
        service -->> controller: Response(500, false, "db error")
        controller -->> router: Response(500, false, "db error")
        deactivate controller
    end
    
    router -->>- frontend: HTTP Response
```

#### Caso POST /fields/occupied

```mermaid
sequenceDiagram
    autonumber

    participant frontend as Frontend
    participant router as Router
    participant controller as :FieldController
    participant service as :FieldService
    participant fieldRepo as :FieldRepository
    participant bookingRepo as :BookingRepository
    participant db as Database

    frontend ->>+ router: POST /fields/occupied
    router ->>+ controller: resolveAction("occupied")
    controller ->>+ service: getOccupiedSlots(fieldId, startDate, endDate)
    service ->>+ bookingRepo: getOccupiedSlots(fieldId, startDate, endDate)
    bookingRepo ->>+ db: query
    db -->>- bookingRepo: occupied slot records
    bookingRepo -->>- service: Slot[]
    
    alt success
        service -->>- controller: Response(200, success, {occupiedSlots: [...]})
        controller -->>- router: Response(200, success, {occupiedSlots: [...]})
    else field not found
        fieldRepo -->> service: throw FieldNotFoundException
        service -->> controller: Response(404, false, "Field not found")
        controller -->> router: Response(404, false, "Field not found")
    end
    
    router -->>- frontend: HTTP Response
```
